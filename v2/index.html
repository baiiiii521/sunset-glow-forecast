06 — HOW IT WORKS / 算法

这台仪器只有三个旋钮，
其余都在打光。

不展开成一门课。三句话讲完，剩下的交给数字。

幕布

权重 0.50

中高云被夕阳从下方点亮，30–70% 最好。

缺口

权重 0.30

沿太阳方位往上游 50–400 km，那边要晴。

低云

权重 0.20

低云是墙，不挡光的天空才有颜色。

霞分 = 幕布0.50 · 缺口0.30 · 低云0.20 × 空气调制 0.7–1.0
几何加权：任一项趋 0，全场趋 0

云量同时取四个数值模式（综合 ×3 / ECMWF / GFS / ICON），各算一遍再加权平均；同一套算法也用于霞榜与每日推送。
