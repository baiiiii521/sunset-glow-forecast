# 页面结构分析（page-structure-analysis）

> 依据：`docs/design/render/*.html` 的真实 DOM 度量（18 个 stage 逐张提取）+ `03-information-architecture.md`
> 坐标单位：CSS px（画布 1440×810）；生产目标视口 1440。

---

## 0. 全局栅格（实测）

| 项 | 值 | 证据 |
|---|---|---|
| 画布 | 1440 × 810（16:9） | 渲染 viewport |
| 左右边距 | **56px**（61 处元素 x=56） | 度量统计 |
| 内容宽 | **1328px** | 1440 − 2×56 |
| 栅格 | 12 栏，栏间距 16–24 | CSS `--col-gap` |
| 顶栏高 | 72px（移动 56px） | `.mast` |
| 常用左半栏宽 | 760 / 720 / 600 / 520 | `.hero-content` 等 |
| 右侧仪器轨 | 224–264px，right:40–96 | `.abs` 侧栏 |
| 卡片边框 | 1px `rgba(246,239,230,.10)` | `--line` |
| 圆角 | 0（容器）/ 999（胶囊按钮） | `--radius` |

**字号实测分布**（18 stage 共 300+ 文本节点）：

| 字号 | 出现次数 | 用途 |
|---|---|---|
| 11px | **184** | mono 标签 / 表头 / 脚注（占绝对多数） |
| 9px | 9 | 极小注（单位、角标） |
| 44 / 52px | 5 / 2 | Section 标题 h1 |

**字体族分布**：JetBrains Mono 197、Noto Serif CJK SC 21、Inter 14 —— 数据与标签几乎全走等宽，标题走宋体，正文走 Inter。

## 结论

- 版式是**严格的 1328 栅格 + 56 边距 + mono 主导**，这三点是「像不像」的关键。
- 18 个 Section 的高度与顺序已在 IA 固定，开发时不得重排。
- 移动端无参考图，是本阶段最大的结构缺口。
