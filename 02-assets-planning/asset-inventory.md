# 素材清单（asset-inventory）

> 原则：只有「真实摄影级天空/环境」才生成图片；布局、图表、图标、纹理、分享卡一律代码实现。
> 结论：**全站只需要 13 张原创图片**（12 天幕 + 1 分享卡底图），其余 93% 视觉由代码绘制。

---

## 1. 目录规范（生产路径）

```
public/assets/
├── photography/
│   └── sky/                 # 天幕：唯一需要 AI 生成的摄影素材
├── generated/
│   └── backgrounds/         # 分享卡底图
├── textures/                # 颗粒/噪声（代码生成，不入库位图）
├── icons/                   # SVG（代码）
└── thumbnails/              # 预留
```

命名：`页面编号_模块编号_素材名称_版本号`
例：`H01_hero_sky_L4_dusk_v01.jpg`

## 4. 分辨率限制（必须知悉）

`codex-image` 走本机 Codex 的 `image_gen`，**单次输出约 1672×941**（gpt-image-2 级）。
在 1440 视口、2x DPR 下需要 **2880 宽**，现有素材只有 0.58x。

可选方案（按推荐顺序）：

1. **CSS 层面接受**：底图叠 `saturate(.86)` + 颗粒 + 遮罩，软度被掩盖；1x 屏完全够用。
2. **升采样**：`sips --resampleWidth 2400`（插值，锐度不增加，但减摩尔纹）。
3. **换真实摄影**：天幕是「预测可视化」，用摄影素材需版权；不建议。
4. **等 Codex 生图升级**：若后续支持更大输出，重出即可（Prompt 已存，见 `image-prompt-library/`）。

**当前决策**：先按方案 1 上线，方案 2 作为 2x 屏兜底；不伪造更高分辨率。
