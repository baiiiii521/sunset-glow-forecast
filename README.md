# 全球朝霞晚霞预测 · 火烧云预报

基于大气光学文献与实时气象数据，预测全球任意地点的朝霞、晚霞与火烧云。

打开页面即可用：搜索任意城市（中文地名），实时查看今明两日共四场（今日朝霞 / 今日晚霞 / 明日朝霞 / 明日晚霞）预测——等级（无烧 / 小烧 / 中烧 / 大烧）+ 评分 + 置信度 + 剧本类型 + 理由 + 最佳观测窗。另有「今日晚霞榜」（全球 TOP 10 + 全中国 TOP 10）与地点收藏。

## 功能

- **城市搜索**：中文地名搜索（Open-Meteo 地理编码）。已处理同名消歧：中文名查不到大城市时，同时补查「市」后缀变体（如「南阳」→「南阳市」），合并去重后按行政等级 + 人口重排，地级市优先于乡镇；候选行显示所属市。
- **四场预报**：对选定坐标实时拉 Open-Meteo 预报（分层云量、降水、能见度、CAPE 等）+ 空气质量（CAMS 的 AOD、PM2.5），用文献启发式算法评分。
- **结论优先**：每场先给一句话结论（「有一点·小烧 / 有·中烧 / 基本没有」）+ 行动建议（值得专门去看 / 顺便看看就行 / 不用等了）+ 一句主因；置信度翻成白话并说清方向（贴下边界→「把握不大，可能比这更差」；贴上边界→「可能比这更好」）。分数、理由、11 项明细、科学原理默认折叠，点「为什么这样判断？」展开核对。
- **自动定位**：用户第一次点击页面时定位一次（搜索框旁也有定位按钮）。HTTPS 下优先用浏览器 GPS / Wi-Fi 定位；HTTP 访问、拒绝授权或超时时，按 IP 估算到城市。逆地理编码与 IP 定位用 BigDataCloud 免 key 客户端接口。用户手动选过地点后不再自动覆盖。
- **天幕即界面**：首屏天空、云底光照、太阳与水面倒影都由选中场次的评分驱动。云层用 SVG 分形噪声 + 自下而上的漫射光照生成，铺在透视平面上；太阳缓慢下沉、光束摆动、水面闪烁。`prefers-reduced-motion` 时只停闪烁类效果，漂移放慢。
- **霞历**：今明两日四场并排，点哪一场，天幕、时间轴、剖面一起切换。
- **天色时间轴**：以选中场次为中心前后 2.5 小时，可拖动 / 自动播放；拖动走 pointer 事件，手机上横向滑动即可，竖向仍能滚动页面。按当地真实太阳高度角划分 白昼 · 金色时刻 · 火烧云 · 蓝调时刻 · 浅黑 · 黑 六段，天色逐分钟渐变。霞强度曲线 = 评分 × 以高度角 −2° 为峰的钟形曲线，**是示意，不是算法输出**。
- **大气剖面**：11 项因素按它们在大气中的高度排列成层，缺数据的层显示「无数据」。
- **霞榜**：城市落在世界（或中国）坐标带上，叠加此刻的日落经度线；全球 36 座 + 中国 34 座大城市，用与单点查询完全相同的算法批量计算各自下一场晚霞，按评分（同分看置信度）排出全球 TOP 10 与全中国 TOP 10，点行直接查该城市。30 分钟缓存。
- **收藏地点**：localStorage 持久化，可添加 / 删除 / 点击切换。
- **容量说明**：页面内有专区说明 Open-Meteo 免费层限额与推算容量（估算值）。

## 算法（与 `sunset-forecast/predict.py` 一致）

科学依据：Corfidi《The Science of Sunsets》（NOAA/NWS）、SOLA 2013 辐射传输模拟、SkyCandy 6 规则 / SunsetWx / Skyfire 启发式。完整文献见研究笔记。

11 项加权评分（权重合计 97）：中高云幕布 30 · 低云 20 · 太阳方向晴空缺口 20（沿日出/日落方位角取上游 50/150/300 km 三点）· 霞时刻降水 10 · AOD 5（倒 U 形，最红点总光学厚度约 0.1）· 能见度 3 · PM2.5 3 · 露点差 2 · 风速 2 · CAPE 2；雨后洗净为纯加成 0–3 分。偏南风 + AOD 高扣 5 分（跨境烟霾风险）。**霞时刻降水直接封顶 40 分（最高小烧）。**

等级阈值：≥75 大烧 · 55–74 中烧 · 35–54 小烧 · <35 无烧。置信度按分数离最近等级边界（35/55/75）的距离：≥12 高 · 6–12 中 · <6 低；缺失关键数据时最高为中。

## 部署

### GitHub Pages

1. 把本仓库推到 GitHub。
2. 仓库 → Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`，Branch 选择 `main` / `(root)`，保存。
3. 访问 `https://<你的用户名>.github.io/<仓库名>/`。

### Vercel

1. 在 [Vercel](https://vercel.com/) 导入本仓库。
2. Framework Preset 选择 `Other`（纯静态，无需构建命令），直接部署。

### Netlify

1. 在 [Netlify](https://www.netlify.com/) 选择 `Add new site` → `Import an existing project`，导入本仓库。
2. Build command 留空，Publish directory 填 `.`（仓库根目录），部署。

## 数据来源

- Open-Meteo 预报 API（https://open-meteo.com/）：分层云量、降水、降水概率、能见度、气压、风、CAPE、日出日落。
- Open-Meteo 空气质量 API（基于 CAMS）：AOD（550nm）、PM2.5、PM10、沙尘。
- Open-Meteo 地理编码 API：城市搜索。
- 以上均为免费接口，无需注册、无需密钥。免费层限额：600 次/分钟、10,000 次/天（以官方最新政策为准）。

## 局限性（请认真读）

- 本预报为基于已发表文献的**启发式算法**，非官方气象预报；学界目前没有经过同行评审验证的“晚霞颜色指数”模型。预报准确度上限即数值天气预报本身的准确度。
- 大烧 / 小烧分级为**待本地照片校准的操作定义**（方位覆盖 + 持续时间 + 主色 + 余晖），不是既有科学标准。
- 缺数据时页面明确显示“无数据”，绝不编造。空气质量数据为 CAMS 全球域（约 45 km 分辨率、3 小时），局地精度有限。
- 本站为纯静态站，所有查询在浏览器端实时发出，不收集、不上传任何个人数据。收藏与榜单缓存仅保存在浏览器 localStorage。
