## 3. 模式权重：移出 CMA，综合 ×3（本次改动）

各模式单独的吻合度，三天看下来：综合最稳；ECMWF 次之；ICON 时好时坏；**CMA 最差且最不稳定**（9 段里 5 段 < 0.6，最低 0.14 / 0.24）。

用 10-20、10-21 两天新公式的各模式分，离线试权重（加权平均只依赖各模式分，离线结果与线上一致）：

| 方案 | 回顾均值（3 段） | 预报均值（6 段） |
|---|---|---|
| 现行：综合 2、其余 1（含 CMA） | 0.758 | 0.770 |
| 等权 | 0.729 | 0.740 |
| 综合 3 | 0.778 | 0.781 |
| **综合 3、去 CMA（采用）** | **0.785** | **0.802** |
| 只用综合 | 0.806 | 0.792 |

10-19（旧缺口公式下）复核：现行 0.78 / 0.89 / 0.76，采用方案 0.72 / 0.88 / 0.83，均值持平。

**没选「只用综合」**：
1. 多模式还要用来告诉用户「几个模式看好」，这是置信度的来源；
2. 对方的数据源大概率和 Open-Meteo 综合模式同类（隔天 → 回顾里「只用综合」高达 0.97），全押综合等于向对方的数据源靠拢，不等于更接近真实天空。
另外移出 CMA 少一个模式，多模式请求的变量数减少约 20%。

## 4. 仍然存在的问题

- 我们的分数分布仍偏扁：104 点里中到大烧以上通常 0–9 个，大烧几乎没有；对方每天各段都有。属于表达 / 阈值问题，与 ERA5 校准线的结论一致，等样本够了一起校。
- 对方的「回顾」是否是实拍汇总仍不清楚；如果它也是模式重算，那么所有「吻合度」都只是「和同类数据源像不像」。真正的实况仍需照片 / 用户反馈。
