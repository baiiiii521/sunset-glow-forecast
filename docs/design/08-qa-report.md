## 5. 设计交付的验收口径

一个 section 可以交付，必须同时满足：

1. 3 秒内能说出这一屏要你做什么（或让你知道什么）。
2. 所有数字有单位、有来源、有等级色。
3. 没有任何装饰元素比主读数更亮。
4. 缩小到 25% 仍能看出层级。
5. 数据缺失处有明确标记，而不是留白或显示 0。
