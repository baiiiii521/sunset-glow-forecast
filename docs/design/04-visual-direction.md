# 04 · 全站视觉方向（PHASE 03）

---

## 1. 一句话方向

**把天空做成一台仪器：电影感的光，仪器级的读数，杂志级的排版。**

三条支柱，缺一条就不成立：

| 支柱 | 含义 | 反面（禁止） |
|---|---|---|
| **天幕为真** | 天空是产品本体，由真实云量/太阳高度/AOD 驱动 | 拿一张固定星空图当背景 |
| **决策优先** | 每一屏先给结论，再给证据 | 把分数藏在装饰字后面 |
| **仪器感** | 细线、刻度、等宽数字、精确对齐 | 圆角卡片堆、发光按钮、渐变药丸 |

---

## 2. 参考坐标（学什么，不抄什么）

| 参考 | 学什么 | 不抄什么 |
|---|---|---|
| 天文台 / 星图软件（Stellarium、Sky Guide） | 刻度、方位、时间轴的**物理真实感** | 拟物化的仪表盘 |
| 电影片头（Saul Bass、Blade Runner 2049 字幕） | 大字号 + 极窄字距 + 缓慢淡入的**节奏** | 光晕滥用 |
| 日本编辑设计（《Casa Brutus》《&Premium》） | 分区编号、细规则线、**留白即结构** | 小清新配色 |
| NASA / ESA 图像页 | 数据的**公信力**：原始参数、采集时间、来源 | 蓝色科技渐变 |
| Aesop / COS 官网 | **克制**：一个页面只说一件事 | 极简到没有信息 |
| Awwwards 站（如 Resn、Locomotive 的作品） | 滚动编排与**页面级过渡** | 为动效而动效 |

### 视觉关键词落地

- **Cinematic**：天幕用真实摄影级色彩关系（不是滤镜），黑位压到 #06050E，高光只给分数与地平线。
- **Atmospheric**：整页允许「雾」——低对比的大气层渐变作为分区之间的过渡，不用硬分隔线。
- **Immersive**：首屏天幕贯通视口，内容悬浮其上；滚动时天幕缓慢位移（parallax ≤ 8%）。
- **Premium**：只用两种字重关系（900 display / 400 body）+ 一种等宽；不用阴影，用 1px 线与透明度分层。
- **Futuristic**：数据用等宽字 + 刻度 + 极小号大写标签，像仪表读数，而不是「科技蓝」。
- **Editorial**：编号 01–05、跨栏大标题、非对称留白、斜体拉丁点缀。
- **Minimalism**：每屏最多 1 个强调色元素。
- **Data Visualization**：所有图表共享同一套刻度语法（见 05 文件）。

## 3. 色彩系统

### 3.1 基础色（Surface & Ink）

| Token | HEX | 用途 |
|---|---|---|
| `--ink-900` | `#06050E` | 页面底色（比现状更深，让天幕发光） |
| `--ink-800` | `#0B0918` | 卡片/浮层底 |
| `--ink-700` | `#120E26` | 次级面板 |
| `--twilight-600` | `#1B1140` | 天幕深色端 |
| `--twilight-500` | `#2A1A55` | 天幕中间调 |
| `--cream` | `#F6EFE6` | 主文字（暖白，非纯白） |
| `--mist` | `rgba(246,239,230,.62)` | 次级文字 |
| `--veil` | `rgba(246,239,230,.38)` | 三级文字/标签 |
| `--line` | `rgba(246,239,230,.10)` | 分隔线（1px） |
| `--line-strong` | `rgba(246,239,230,.22)` | 强调分隔 |

### 3.2 品牌色（Brand）

| Token | HEX | 用途 |
|---|---|---|
| `--ember` | `#FF5A1F` | 唯一主强调色：当前选中、CTA、门控三项 |
| `--gold` | `#FFC36B` | 高光：大烧、最红时刻、太阳 |
| `--rose` | `#FF7E8B` | 中段霞色：小烧、云边 |
| `--plasma` | `#B14BFF` | 未来/预测（仅用于「明日」「集合分布」） |

### 3.3 六级色阶（核心资产）

分数 → 颜色，一望即读。这是现状最缺的一套语义。

| 等级 | 区间 | Token | HEX | 视觉处理 |
|---|---|---|---|---|
| 无烧 | 0–19 | `--lv0` | `#6E6A80` | 中性灰紫，无光 |
| 微烧 | 20–34 | `--lv1` | `#8C7BB8` | 冷紫，细描边 |
| 小烧 | 35–49 | `--lv2` | `#FF7E8B` | 玫瑰，轻微发光 |
| 小到中烧 | 50–64 | `--lv3` | `#FF9F45` | 琥珀，发光增强 |
| 中到大烧 | 65–79 | `--lv4` | `#FF5A1F` | 主 ember，明显发光 |
| 大烧 | 80–100 | `--lv5` | `#FFC36B` | 金，外发光 + 极轻 bloom |

> 规则：色阶只用于**分数相关**的元素（分数、色条、地图点、柱状图）。不要拿色阶给按钮上色——按钮永远是 ember 或描边。

### 3.4 天幕渐变（由数据驱动，不是固定图）

四段光谱，按太阳高度插值：

```
−18°   #06050E → #0E0B22        （夜）
−10°   #0E0B22 → #241441        （天文暮光）
 −4°   #241441 → #7A1A58        （民用暮光·紫）
 −1°   #7A1A58 → #FF5A1F        （火烧窗口）
 +6°   #FF5A1F → #FFC36B        （金色时刻）
+15°   #FFC36B → #FFE9C7        （白昼前）
```

叠加层：`feTurbulence` 生成的三层云（高/中/低），各自的阈值由该层云量决定——云多则噪声阈值降低，云层更实、更暗。

### 3.5 明暗模式

**只做暗色。** 理由：产品是「看天」，暗底是内容的一部分；浅色模式会让天幕失去意义。P05 方法页的 cream 反色是**版式策略**，不是浅色主题。

## 4. 字体与排版

### 4.1 字体族

| 角色 | 字体 | 理由 | 自托管 |
|---|---|---|---|
| Display（中文） | **Noto Serif SC** 900 | 高对比宋体，有年历感；现状已验证 | ✅ 必做（子集化，约 120 KB） |
| Display（拉丁斜体） | **Instrument Serif** Italic | 城市拉丁名、引文，制造编辑感 | ✅ |
| Body（中文/拉丁） | **Inter** + **PingFang SC / Noto Sans SC** 回退 | 屏幕可读性最好 | Inter 自托管，中文走系统 |
| Data | **JetBrains Mono** 400/600 | 等宽数字，仪器感；现状已用 | ✅ 子集化 |

> 硬规则：**不得直连 Google Fonts**。全部 `woff2` 自托管 + `font-display: swap` + `unicode-range` 子集。

### 4.2 字号阶梯（fluid，clamp）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-display` | `clamp(72px, 11vw, 176px)` | 页面级巨大词（今晚 / 烧） |
| `--fs-h1` | `clamp(40px, 5.2vw, 84px)` | section 主标题 |
| `--fs-h2` | `clamp(28px, 3vw, 44px)` | 模块标题 |
| `--fs-h3` | `clamp(20px, 1.8vw, 26px)` | 卡片标题 |
| `--fs-body` | `clamp(15px, 1.05vw, 17px)` | 正文 |
| `--fs-small` | `14px` | 辅助 |
| `--fs-label` | `11px` / 字距 `.14em` / 大写 | mono 标签、编号 |
| `--fs-data-xl` | `clamp(96px, 14vw, 200px)` | 分数主数字 |
| `--fs-data-l` | `clamp(40px, 4vw, 64px)` | 卡片内分数 |

行高：display  `.92` / h  `1.08` / body `1.72` / label `1.2`。
字距：display `−.03em` / h `−.015em` / body `0` / label `+.14em`。

### 4.3 排版母题（全站复用的 5 个动作）

1. **分区编号**：`01 —` 起头，mono 11px，后面跟中文短词。所有页面统一。
2. **大词 + 小注**：一个 100px 的词 + 一行 14px 的注，形成垂直张力。
3. **细规则线**：1px `--line` 横贯内容区，用于切分而非留白。
4. **右对齐数据**：所有数字列右对齐，使用 `font-variant-numeric: tabular-nums`。
5. **斜体拉丁点缀**：每页最多 2 处，只用于城市名或引文。

## 5. 图像策略

### 5.1 三层图像

| 层 | 内容 | 生产方 |
|---|---|---|
| L1 天幕 | 由代码实时渲染的天空（非位图） | 现有 SVG 滤镜升级 |
| L2 摄影 | 观景点实景、霞榜城市、方法页插图 | **codex-image 生成**，统一调色 |
| L3 图表 | 所有数据图形 | 代码渲染（SVG/Canvas） |

> 禁止：用 L2 的摄影图当首屏背景（会与 L1 的天幕打架，也是最常见的「廉价感」来源）。

### 5.2 摄影素材规范

- 比例：观景点卡 4:5、城市头图 21:9、分享卡 1.91:1。
- 调色：暗部保留，高光压在 `#FFC36B` 以内；饱和度不超过 60%；统一加 3% 颗粒。
- 内容：必须有**地平线与前景遮挡关系**（能看出「这里是能看见天的」），不要纯天空壁纸。
- 数量：全站 ≤ 24 张，同一页面不重复。

### 5.3 AI 生成素材的诚实标注

任何示意性的观景点/照片，在实现阶段必须在 UI 中标注来源（`示意` / `AI 生成`），不得冒充实拍。方法页的失败案例照片则使用**真实用户照片**（已有：`data/obs/2026-10-23_hcm_1744.jpg`）。

## 6. 动效原则

**一条总则**：动效只做两件事——**表达时间流逝**，或**表达层级变化**。其余一律静态。

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 天幕换场（切换朝/晚） | 900ms | `cubic-bezier(.16,1,.3,1)` | 渐变 + 云层阈值交叉淡入 |
| 滚动入场 | 700ms | 同上 | `translateY(24px)` + 透明度，stagger 60ms |
| 数字滚动 | 1200ms | ease-out | tabular-nums，不跳位 |
| 时间轴拖动 | 120ms | linear | 跟手，天幕不重绘整层，只调渐变 stop |
| 悬停（榜单/地图点） | 180ms | ease-out | 只改透明度与 1px 描边，不缩放 |
| 页面切换（View Transitions） | 500ms | 同主曲线 | 天幕做共享元素过渡 |
| 视差 | — | 滚动线性映射 | 最大位移 8%，`transform: translate3d` |

`prefers-reduced-motion`：关闭视差、stagger、数字滚动，天幕过渡降为 200ms 淡入。

## 7. 五个页面的视觉差异与统一

| 页面 | 构图策略 | 与全站的统一锚点 |
|---|---|---|
| P01 今晚 | 全幅天幕 + 左重右轻 + 右侧仪器轨 | 天幕、分数色阶、编号语法 |
| P02 城市 | 左 sticky 结论 + 右滚动数据（像一份观测报告） | 同一套图表语法 |
| P03 霞榜 | 地图即画布，榜单浮在上面 | 同一套色阶与城市点 |
| P04 观景点 | 地平线剖面为主视觉（横向长图） | 同一套摄影调色 |
| P05 方法 | **cream 反色纸面** + 墨色，像杂志插页 | 同一套字体与编号 |

> 统一的检验方法：把 5 个页面缩到 25% 并排，应该一眼看出是同一个产品——因为天幕、色阶、mono 刻度、编号语法四条线索始终在场。

## 8. 反模式清单（设计评审直接打回）

1. 圆角 ≥ 12px 的卡片堆砌（本产品用 0–2px 直角或 999px 药丸，二选一，不混用）。
2. 蓝紫渐变按钮 + 外发光（典型 SaaS 味）。
3. 用 emoji 当图标（🔥 满天飞）。
4. 同一屏超过 2 种强调色。
5. 玻璃拟态滥用（`backdrop-filter` 只允许出现在 masthead 与抽屉）。
6. 图片上加彩色叠加层压字（除非有 >= 4.5:1 的遮罩保证）。
7. 「AI 味」的空话文案（`探索无限可能`）。
8. 装饰性大数字没有单位、没有刻度、没有解释。
