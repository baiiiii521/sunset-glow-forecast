# 10 · 天幕分级系统（Sky Library）

> 目标：首屏的天不是一张图，而是**按预测结果切换的一整套天空**。
> 六个等级 × 朝/晚两态 = 12 张底图，UI 永远同一套。

---

## 1. 为什么要这么做

晚霞产品的可信度，一半来自数字，一半来自"你看到的天和你读到的分数一致"。

- 预报 20 分（微烧）却配一张漫天大烧的照片 → 用户立刻觉得假。
- 预报 78 分（中到大烧）却配一张灰蓝天空 → 用户觉得"这产品不懂霞"。

所以天幕必须是**分数的函数**，而不是一张固定的氛围图。

---

## 2. 分级映射（与 algo.js 的六档完全对齐）

| 等级 | 分数区间 | 底图（晚） | 底图（朝） | 画面特征 |
|---|---|---|---|---|
| L0 无烧 | 0–19 | `sky-dusk-L0.jpg` | `sky-dawn-L0.jpg` | 厚低云 / 平灰蓝，无暖色 |
| L1 微烧 | 20–34 | `sky-dusk-L1.jpg` | `sky-dawn-L1.jpg` | 地平线一线淡桃色，云边微亮 |
| L2 小烧 | 35–49 | `sky-dusk-L2.jpg` | `sky-dawn-L2.jpg` | 三成云被点亮，玫瑰+浅琥珀 |
| L3 小到中烧 | 50–64 | `sky-dusk-L3.jpg` | `sky-dawn-L3.jpg` | 半个天的层积云被点亮 |
| L4 中到大烧 | 65–79 | `sky-dusk-L4.jpg` | `sky-dawn-L4.jpg` | 大部分天空橙金，对比强 |
| L5 大烧 | 80–100 | `sky-dusk-L5.jpg` | `sky-dawn-L5.jpg` | 漫天绯红/熔金，仍保持摄影真实 |

**选图规则（实现）**

```ts
const band = score>=80?5 : score>=65?4 : score>=50?3 : score>=35?2 : score>=20?1 : 0;
const plate = `${isSunrise ? 'sky-dawn' : 'sky-dusk'}-L${band}.jpg`;
```

**注意**：选图只看 `score`，不看 `grade` 文案；分档边界与 `LEVELS` 一致（20/35/50/65/80）。

---

## 3. 过渡与加载

| 项 | 规格 |
|---|---|
| 切换（换场/换城市） | 900ms 交叉淡入，主曲线 `cubic-bezier(.16,1,.3,1)`；不缩放、不平移 |
| 首屏加载 | 先出 CSS 渐变（同色系）→ 底图 `onload` 后 400ms 淡入，避免白闪 |
| 预加载 | 只预取当前 ±1 档（相邻两场），不预取全部 12 张 |
| 体积 | 每张 1672×941 JPEG ≈ 1.9MB → 上线前压到 2400×1350 / q78 ≈ 350KB，并出 WebP |
| 失败回退 | 图片 404/超时 → 用 `--lv{n}` 主色做双色渐变（不显示"裂图"） |

---

## 4. 设计约束（12 张必须共享）

1. **构图**：地平线压在画面 80% 高度；左 1/3 更暗更平（放标题与分数）。
2. **不含元素**：无陆地、无水面、无月、无星、无文字、无 UI、无水印。
3. **色调**：L0–L2 冷色为主（蓝灰/淡紫），L3 起暖色逐级增加；L5 允许绯红但不得霓虹。
4. **光照一致性**：所有图的光源都在右下方低空（与日落方位 257° 的默认叙事一致）。
5. **压饱和**：CSS 统一 `saturate(.86) contrast(1.03) brightness(.92)`，再叠 10% 颗粒。

## 6. 已知限制

- 目前一天只有一场（今/明 × 朝/晚）会切图；**一天内的连续变化（16:00→19:00）仍靠 01-04 时间轴的 CSS 渐变**，不是 12 张逐小时图。
- 12 张是"六档 × 两态"的离散映射，档内没有强度差异（例如 66 和 79 用同一张）。若要更细，可按 10 分一档扩到 20 张，成本线性上升。
- L4/L5 的区分对普通用户偏弱，主要靠"云被点亮的面积"和"红的深度"，落地时建议再做一次并排盲测。
