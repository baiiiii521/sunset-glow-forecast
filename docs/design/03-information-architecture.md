> 2026-10-23 修订：按 Barry 的反馈删掉「观景点」与「成绩单」，方法页从独立页面降级为首页的一个概述区块。

## 1. 页面数量：3 个

| # | 页面 | 一句话职责 | 为什么必须单独存在 |
|---|---|---|---|
| P01 | **今晚** `/` | 3 秒回答「今晚值不值得去」 | 唯一高频入口，承载 80% 访问 |
| P02 | **城市** `/c/:slug` | 一个城市的完整情报与 7 天 | 可被搜索、可被分享的原子单位；解决 SEO 与「换城市」 |
| P03 | **霞榜** `/board` | 今天全球/中国哪里最可能烧 | 社交传播抓手；把「我的城市」放大到「世界」 |

**不是页面的东西**
- 算法说明 → P01 的第 7 个 Section（`#brief`），三段话 + 一组数字，不单独成页
- 搜索 / 城市切换 → ⌘K 面板
- 收藏 → 顶栏抽屉
- 分享卡 → 浮层

**已删除（附理由，避免以后又加回来）**

| 砍掉的 | 理由 |
|---|---|
| 观景点 `/c/:slug/spots` | 城市无限，逐城地平线数据无法维护；也不做用户上传 |
| 城市成绩单 02-06 | 逐城统计需要 50+ 样本才有意义，绝大多数城市永远到不了 |
| 方法页 `/method` | 用户不需要一堂课，需要三句话 + 一个可信的数字 |

## 2. Sitemap

```
/                       P01 今晚（默认定位城市）
│   ├── #rail           四场轨道
│   ├── #timeline       天色时间轴
│   ├── #profile        大气剖面
│   ├── #board          霞榜预告
│   └── #brief          算法概述（替代原方法页）
├── /c/:slug            P02 城市详情（?d=YYYY-MM-DD 定位某一天）
├── /board              P03 霞榜（?scope=china|global）
└── 系统态
    ├── ⌘K 搜索面板（城市 / 拼音 / 经纬度 / 收藏）
    ├── 收藏抽屉
    ├── 分享浮层
    └── 错误 / 空态 / 离线
```

**一级导航（3 项）**：`今晚` · `霞榜` · `算法`（锚点到 `#brief`，不再是独立页）

> 城市页不进导航，靠搜索与 URL 进入——它必须是「可被搜索的入口」，不是「需要记住的标签」。

# P01 · 今晚（`/`）

**核心目标**：3 秒内让用户知道今晚值不值得出门、几点、朝哪看。
**入口**：直接访问、分享卡、搜索引擎「XX 今晚晚霞」。
**桌面布局**：12 栏栅格，左 7 栏内容、右 4 栏仪器轨、1 栏留白；天幕作为 100vw 底层。

### 01-01 Masthead 顶栏
- 72px，透明浮在天幕上；滚动 120px 转 `backdrop-filter: blur(18px)` + 1px 底线。
- 左：`霞` 印章 + 字标「GLOW / 火烧云预报」。
- 中：3 个导航（01 今晚 / 02 霞榜 / 03 算法）。
- 右：搜索（⌘K）、收藏、分享。
- 移动端 56px：印章 + 当前页名 + 搜索；导航进底部 3 段 tab bar。

### 01-02 Hero Verdict 今晚结论
- 全幅天幕（AI 摄影底图 + 遮罩，UI 全部代码渲染）。
- 地点行 `胡志明市 · Thủ Đức ｜ 10.79°N 106.75°E ｜ 15:02 更新`
- 主词 `今晚`（118px）；分数（184px，色阶色）+ `/100` + 等级词 `中到大烧`
- 行动句：`值得跑一趟。` + 一行解释 `西边有缺口，云幕刚好。`
- 决策行：`最佳窗口 17:19–17:58`（40px ember）／日落 17:32／方位 257°
- 四枚胶囊：把握 中 · 通透 61 一般 · 集合 51 中位 71 · P(小烧+) 94%
- 主 CTA `看这七天的霞` + 次 CTA `分享卡片`
- 右侧仪器轨：太阳高度时间尺（−18°→+6°）+ 四模式读数（加权 综合×3）
- 移动端：分数 96px，仪器轨折叠为三枚胶囊。

### 01-03 四场轨道 Forecast Rail
- 4 格：今朝 / 今晚 / 明朝 / 明晚；每格时段名 + 时刻 + 分数 + 色条 + 一句理由。
- 选中格 2px ember 顶线，天幕 900ms 过渡。
- 下方补一组「为什么今晚更高」的门控读数（幕布 / 缺口 / 低云）。

### 01-04 天色时间轴 Sky Timeline
- 全幅舞台 + 96px 时钟 + 太阳高度 + 霞强度（x/100）。
- 150 格刻度（每格 2 分钟）+ 游标把手 + 三段区间（蓝调 / 火烧 / 金色）。
- 拖动、点击、`←→`、空格播放。

### 01-05 大气剖面 Atmosphere Profile
- 11 项按高度分组：8–12 km / 0–2 km / 上游 50–400 km / 地面。
- 每行：得分条 + 权重 + 分值；门控三项 ember，其余灰阶。
- 缺数据：空心虚线 + 「无数据 · 退出加权」。

### 01-06 霞榜预告 Board Teaser
- 大标题 `今天傍晚，哪些城市最可能烧起来？`
- 右：TOP5 迷你榜（名次 / 城市 / 日落 / 分数）。
- 底：96px 地球带（1px 海岸线 + 晨昏线）。
- 点击行 → 城市页；点击标题 → `/board`。

### 01-07 算法概述 Algorithm Brief（替代原方法页）
- 标题：`这台仪器只有三个旋钮，其余都在打光。`
- 三列：`幕布 ×0.5` / `缺口 ×0.3` / `低云 ×0.2`，各一句人话。
- 下半：几何加权 + 四模式 + 51 集合成员；右侧三个数字（模式 4+51 / 更新每小时 / 命中 ±1 档 68%）。
- 末行：已知误判 `2026-10-23 胡志明市，预报 31（微烧），实拍小烧——雨晚到一小时，触发降水封顶`。
- 交互：末尾链接可展开完整方法（抽屉，内容按需加载）。

### 01-08 Footer
- 三列：数据（Open-Meteo / CAMS / BigDataCloud）｜算法（霞分 v2.2 · 4 模式 · 51 成员）｜声明（纯静态 · 查询在浏览器发出 · 不收集个人数据）。

# P02 · 城市（`/c/:slug`）

布局：左 380px sticky 结论栏 + 右侧滚动数据区。

### 02-01 City Header
- 城市名（84px）+ 拉丁斜体 + 国家/坐标/时区 + 收藏 + 分享。
- 右栏 sticky：今晚分数 / 窗口 / 明晚与次高分。
- 底部：本周最高 + 霞榜排名 + 7 根迷你柱。

### 02-02 七日矩阵 Seven-Day Matrix
- 7 列 × 3 行（晚霞 / 朝霞 / 日落）；最高分列 ember 描边 + `本周最有机会`。
- 点击列 → `?d=` 更新，下方模块切到该日。

### 02-03 云层剖面 Cloud Deck
- 地平线弧 + 三层云带（8.6 / 5.2 / 1.2 km）+ 太阳方位光线 + 上游 5 点（50–400 km）。
- 右侧门控得分卡（幕布 / 缺口 / 低云 + 几何合成）。

### 02-04 模式分歧 Model Consensus
- 四模式点阵轴（0–100）+ 51 成员分布（P10/P50/P90）+ 一致度结论。
- 分歧大时显式写「各家意见分裂，别太当真」。

### 02-05 日落时序 Sunset Sequence
- 8 格天幕切片（17:08 → 18:12），标「最红 17:33–17:41」与颜色名。

> 原 02-06 城市成绩单已删除（数据成本不成立）。

# P03 · 霞榜（`/board`）

### 03-01 Board Header
- 标题 + 一句读解（34 城 / 16 城有霞 / 最高 79）+ scope 切换 + 日期 + 更新时间 + TOP4 带。

### 03-02 地图 + 榜单（合并版）Map & Ranking
- **地图与榜单同屏**：左侧 392px 浮动榜单面板，右侧地图（中国范围自动放大 2.1×，原点对准中国）。
- 面板：scope 分段（中国 / 全球）、TOP10（名次 / 城市 / 霞分 / 色阶条 / 把握）、`点径 = 分数` 说明。
- 地图：中国轮廓完整可见，城市点按等级着色，前 3 名带标签；右上角色阶图例 + 城数口径。
- 切换 scope 时地图缩放锚点同步变化（全球 1×，中国 2.1×）。
- **不做**：单独的榜单页/长列表——榜单永远贴在地图上。

### 03-03 双榜对照 Dual Board
- **一张世界地图 + 底部双榜**：上半地图（520px），下半左右两栏「中国 TOP5 / 全球 TOP5」。
- 地图上给两个 #1 城市加气泡（CHINA #1 南阳 78 / GLOBAL #1 雅典 73），其余点不标名，避免拥挤。
- 两栏各自标口径：中国 34 城 · 10 城有霞；全球 36 城 · 23 城有霞。
- **不做连线**：跨半球长连线在深色地图上不可追踪，改用气泡锚点。

### 03-04 分布直方 Fig Distribution
- 六档柱状（无烧 → 大烧）+ 大盘读数（参评 / 有霞 / 值得跑）+ 全球榜对照。

### 03-05 城市检视 City Inspector
- 桌面右侧抽屉 420px；移动底部 sheet 78vh。
- 内容：城市 + 分数 + 等级 + 日落 + 门控三条 + `查看城市页 →`。

## 4. 全局组件与状态

| 组件 | 说明 |
|---|---|
| ⌘K 命令面板 | 城市搜索（中/英/拼音/经纬度）、最近访问、收藏、页面跳转 |

| 分享浮层 | 1200×630 天幕卡预览 + 复制链接 |
| 加载态 | 天幕先出，数据占位 `--` + shimmer |
| 错误态 | 网络失败 / 429 限流 / 数据缺失，三套文案 |
| 空态 | 未定位时的「你在哪里看霞」引导 |
| 减弱动效 | 关视差、关 stagger，天幕过渡 200ms 淡入 |
