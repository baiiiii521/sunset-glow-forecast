# P01 · 今晚 `/`

全页高度 ≈ 5.5 屏。天幕为 100vw 底层，`position:fixed` 于 0–120vh 区间内，随滚动产生 ≤8% 位移。

## 01-01 Masthead

- **目标**：不抢戏地钉住品牌与三个入口，滚动后仍然可操作。
- **布局**：72px 高，全宽，`display:flex; justify-content:space-between`；左中右三组，中组绝对居中。
- **内容**：印章「霞」+ `GLOW` / `今晚` `霞榜` `方法` / 搜索、收藏、分享。
- **视觉**：默认透明；滚动 >120px 后毛玻璃 + 1px 底线。导航字号 11px mono，编号与文字之间用 6px 空格。
- **交互**：点击当前页不滚动；搜索展开 ⌘K 面板（全屏遮罩 + 居中输入）。
- **移动端**：56px；显示「霞」+ 页面名 + 搜索图标；导航移入底部 tab bar。

## 01-02 Hero Verdict（今晚结论）

- **目标**：3 秒回答「今晚值不值得去、几点、朝哪」。
- **布局**：`min-height:100vh`；12 栏：左 7 栏内容（顶部 22vh 起），右 4 栏仪器轨，右 1 栏留白。
- **内容（固定顺序）**
  1. 地点行：`胡志明市 · Thủ Đức ｜ 10.79°N 106.75°E ｜ 21:16 更新`（11px mono，`--veil`）
  2. 主词：`今晚`（display 176px，cream，letter-spacing −.03em）
  3. 分数：`42`（data-xl，色 = `--lv2`）+ `/100` + 等级词 `小烧`
  4. 行动句：`顺路看看就行，别专程跑。`（20px，`--mist`，max-width 32ch）
  5. 时间窗组：`17:32 日落` / `最佳 17:17–18:02` / `方位 257°`（mono，24px，用 `·` 分隔）
  6. 事实胶囊：`把握 高` `通透 22/100` `集合 51 成员 中位 34`
  7. 主 CTA：`看这七天的霞`（ghost→primary 二选一，每页仅此一个）
- **视觉**：天幕占满视口，地平线压在下 22%；所有文字左对齐在同一 1px 垂直基线上；分数右侧有一条 1px 竖线（高 200px）作为「仪器刻度」的起点。
- **交互**：鼠标移动时天幕层位移 ≤12px（`transform`，`prefers-reduced-motion` 关闭）；点击分数 → 滚动到 01-05 剖面。
- **数据**：`score / grade / probability / window / bearing / conf / ensemble.p50`。
- **移动端**：天幕 60vh；主词 72px；分数 96px；时间窗改为两行；仪器轨折叠为分数下方的三枚胶囊。

## 01-03 四场轨道 Forecast Rail

- **目标**：一眼看到「今天还有没有下一场、明天值不值得等」。
- **布局**：全幅内容区（12 栏），4 等分；上边 1px line，下边 1px line。
- **内容**：每格 = `01 今朝` / `02 今晚` / `03 明朝` / `04 明晚` + 时刻 + 分数 + 等级色条 + 一句理由（示例：`中高云近全覆盖`）。
- **视觉**：未选中 `--mist`，选中 cream；选中格顶部 2px ember。
- **交互**：点击切换 → 天幕 900ms 过渡 + 01-02 全部数字联动；`←→` 键可切。
- **数据**：`days[n].sunset|sunrise`。
- **移动端**：横滑，卡宽 78vw，`scroll-snap-type:x mandatory`。

## 01-04 天色时间轴 Sky Timeline

- **目标**：让「时间」变成可触摸的东西——拖一下就看见天怎么暗下去。
- **布局**：全幅舞台 `height:66vh`；底部控制条 120px（时钟 + 刻度 + 播放 + 阶段图例）。
- **内容**：大时钟（`17:44`，96px mono）、太阳高度（`−3.2°`）、霞强度（`68%`）、阶段名（`火烧云` + 英文 `FIRE`）、一句描述（`光从地平线下点燃云底。`）。
- **视觉**：天幕只换渐变 stop，不重绘噪声（性能）；三个阶段区间在刻度条上以 24px 高的半透明带表示。
- **交互**：拖动/点击轨道、`←→` 逐格（2 分钟）、`Shift+←→` 10 格、空格播放/暂停（8 秒走完全程）。
- **数据**：`sunsetEpoch ± 150min`，每格由 `score × 时间曲线` 计算。
- **移动端**：舞台 50vh，时钟 56px，刻度条保留全宽，阶段名竖排在右边缘。

## 01-05 大气剖面 Atmosphere Profile

- **目标**：把「为什么是这个分」变成一张能看懂的结构图。
- **布局**：左侧高度轴（12km→0），右侧 11 行；行间距 12px；顶部有 3 条水平虚线标注云层高度。
- **内容**：11 项：高云幕布 / 中云幕布 / 上游缺口 / 低云遮挡 / 降水 / AOD / 能见度 / PM2.5 / 露点差 / 风 / CAPE。
- **视觉**：门控三项用 ember 条，其余 `--mist`；每条右侧 `×0.5` 权重；缺失项空心虚线 + `无数据`。
- **交互**：hover 行 → 右侧浮出该项的解释（一句话 + 数据源）；点击 → 打开「因素说明」抽屉。
- **数据**：`inputs` + `comps`。
- **移动端**：高度轴缩为行首徽标，行高 56px，权重列折到第二行。

## 01-06 霞榜预告 Board Teaser

- **目标**：把「我的城市」放大到「世界」，制造传播。
- **布局**：左 520px 大标题；右 TOP5 列表；底部一条 96px 高的地球带（含晨昏线）。
- **内容**：`今天傍晚，哪些城市最可能烧起来？` + `34 城参评 · 16 城有霞 · 最高 79` + 5 行（名次/城市/日落/分数）。
- **视觉**：地球带只用 1px 海岸线 + 晨昏线渐变，不加载瓦片；第一名分数用 data-l 字号。
- **交互**：行 → 城市页；标题区/按钮 → `/board`。
- **数据**：`rankings.china|global` 前 5、`stats.counts`。
- **移动端**：标题 28px，5 行保留（约 320px 高）。

## 01-07 算法概述 Algorithm Brief

- **目标**：三句话讲清「凭什么信你」，不展开成一门课。
- **布局**：标题 + 三列旋钮（幕布/缺口/低云，各带权重）+ 一段说明 + 三个数字 + 一行已知误判。
- **内容**
  - 标题：`这台仪器只有三个旋钮，其余都在打光。`
  - 三列：`幕布 ×0.5`（30–70% 最好）、`缺口 ×0.3`（上游 50–400 km 要晴）、`低云 ×0.2`（低云是墙）
  - 说明：几何加权 + 四模式（综合×3 / ECMWF / GFS / ICON）+ 51 集合成员
  - 数字：模式 `4 + 51`、更新 `每小时`、命中 ±1 档 `68%`
  - 误判：`2026-10-23 胡志明市，预报 31（微烧），实拍小烧——雨晚到一小时，触发降水封顶`
- **视觉**：三列顶部 2px ember；数字 mono 22px；误判行用 mist，不喧宾夺主。
- **交互**：末尾 `这是启发式算法，不是官方预报 →` 可展开完整方法（抽屉，内容来自原 P05，按需加载）。
- **数据**：静态文案 + `LEVELS` 权重，不取实时数据。
- **移动端**：三列转三行，数字行横滑。

## 01-08 Footer

- **目标**：交付信任与来源，不制造第二个注意力中心。
- **布局**：12 栏三等分；高 220px；上边 1px line。
- **内容**：左「数据」Open-Meteo / CAMS / BigDataCloud；中「算法」霞分 v2.2 · 4 模式 · 51 成员；右「声明」纯静态 · 查询在浏览器发出 · 不收集个人数据。
- **视觉**：11px mono，`--veil`，链接 hover 变 cream。
- **交互**：无。
- **移动端**：三列转三行，行距 24px。

# P02 · 城市 `/c/:slug`

布局：左 380px sticky（top:104px）+ 右 7 栏滚动。左栏容纳 02-01 与分数结论，右栏依次 02-02 ~ 02-06。

## 02-01 City Header 城市页头

- **目标**：建立「这是一个可收藏、可分享的实体」的感觉。
- **布局**：左栏顶部；城市名 2 行（CJK 64px）+ 拉丁斜体 20px；下方坐标与坐标时区。
- **内容**：`胡志明市` / `Ho Chi Minh City` / `越南 · Asia/Ho_Chi_Minh` / `10.79°N 106.75°E` / 收藏 / 分享。
- **视觉**：城市名用 display serif；拉丁名用 Instrument Serif italic；两者基线错开 8px。
- **交互**：点击分享 → 浮层展示 1200×630 卡片 + 复制链接。
- **移动端**：非 sticky；标题 40px。

## 02-02 七日矩阵 Seven-Day Matrix

- **目标**：把「这周哪一天值得跑一趟」压缩成一个可扫视的矩阵。
- **布局**：7 列 × 4 行（日期 / 晚 / 朝 / 日落）；列宽 1fr；行高 64px。
- **内容**：日期（`10-28 周三`）、晚霞分、朝霞分、日落时刻；最高分列加 `本周最有机会` 标签。
- **视觉**：每个分值单元格背景 = 等级色 12% 透明度，文字 = 等级色；最高列 1px ember 描边。
- **交互**：hover 列 → 顶部浮出当日一句总结；点击 → `?d=` 更新，02-03/02-04/02-05 全部切到该日。
- **数据**：7 天 `score`（朝/晚）与 `sunset` 时刻。
- **移动端**：横向滚动，列宽 96px；表头固定。

## 02-03 云层剖面 Cloud Deck

- **目标**：把算法里最抽象的「幕布 × 缺口 × 低云」画成物理剖面。
- **布局**：宽 100%，高 420px 的 SVG 画布；地平线弧在底部 1/4。
- **内容**：三层云带（高 8.6km / 中 5.2km / 低 1.2km）、太阳方位光线（从右侧 257° 射入，仰角 −2°）、上游 5 点（50/100/200/300/400 km）疏密表示云量。
- **视觉**：云带用与天幕相同的噪声纹理，密度 = 云量；光线被云遮住部分变为实心暗；缺口处画金色细线。
- **交互**：hover 云带 → 显示「高云 99% · 得分 44 · 权重 ×0.5」；拖动底部滑块可改时间（15 分钟粒度）。
- **数据**：`inputs.high/mid/low`、`upLowAvg`、`upMidAvg`、`peakOffsetMin`。
- **移动端**：高度 280px；上游点减为 3 个。

## 02-04 模式分歧 Model Consensus

- **目标**：让「把握」变成可检验的东西，而不是一个形容词。
- **布局**：上半 4 行（每模式一行点阵轴），下半 51 成员分布（高 160px）。
- **内容**：`综合 34` `ECMWF 34` `GFS 30` `ICON 34`，轴 0–100；分布标 P10/P50/P90；结论句 `4 家一致 · 极差 15 · 把握 高`。
- **视觉**：四个点用 cream，落在同一档内自动连线；分布用竖直细柱（1px 宽，间距 2px）。
- **交互**：hover 点 → 显示该模式的具体云量；点击「这是什么」→ 抽屉解释集合预报。
- **数据**：`ensemble.members`、`ensemble51`。
- **移动端**：模式行改为 2×2 卡片；分布图保留。

## 02-05 日落时序 Sunset Sequence

- **目标**：把「最红时刻」可视化——不是一句话，是 8 格延时。
- **布局**：横向 8 格（每格 1fr），格内 4:3 天幕缩略；下方一条时间轴（−40 ~ +30 min）。
- **内容**：每格标 `17:20 / −12°`；峰值格标 `最红 17:33–17:41`；最后一格标 `蓝调 17:32–17:53`。
- **视觉**：8 格由同一渲染器生成，只改太阳高度；峰值格 1px gold 描边。
- **交互**：hover 格 → 放大 1.04；点击 → 03-01 的天幕跳到该时刻。
- **数据**：`illuminationLimit()` 计算的最红窗口 + 颜色名。
- **移动端**：横滑，格宽 44vw。

# P03 · 霞榜 `/board`

## 03-01 Board Header

- **目标**：先给「今天是不是一个好天」的总判断，再给名单。
- **布局**：高 200px；左侧 h1 + 一句读解；右侧分段控件（中国/全球）+ 日期 + 更新时间。
- **内容**：`今天傍晚，哪里最可能烧起来` / `34 城参评 · 16 城有霞 · 最高 79 分`。
- **视觉**：读解句用 mono，数字用等级色加粗。
- **交互**：切换 scope 时地图与榜单 400ms 交叉淡入。
- **移动端**：h1 32px；控件置底为 sticky。

## 03-02 地图 + 榜单（合并）Map & Ranking

- **目标**：一张屏同时回答「哪里烧」和「谁最烧」，不再分两个模块。
- **布局**：左 392px 浮动面板 + 右侧地图（`transform: translate(-220px,172px) scale(2.1)`，锚点 lon105/lat35）。
- **内容**：面板 = scope 切换（中国/全球）+ 表头（#/城市/霞分/色阶/把握）+ TOP10 + 底部说明；地图 = 中国轮廓 + 城市点（前 3 名带标签）+ 右上色阶图例 + 城数。
- **视觉**：面板 `rgba(6,5,14,.72)` + 1px 边 + `blur(6px)`；面板左侧压一层渐变保证地图不被硬切。
- **交互**：点行 → 城市页；切换 scope → 地图缩放锚点切换（900ms）。
- **数据**：`rankings.china|global`、`stats.counts`。
- ⚠️ **底图合规**：上线前必须替换为带审图号的标准地图（台湾、南海诸岛、九段线齐全）；Natural Earth 仅用于设计稿。
- **移动端**：地图在上（52vh），榜单改为底部可上滑 sheet。

## 03-03 双榜对照 Dual Board

- **目标**：同一张图上比较「中国头名」与「全球头名」。
- **布局**：上 520px 世界地图；下 230px 左右两栏榜单（中间 1px 竖线）。
- **内容**：CHINA TOP5（南阳 78 … 大连 65）、GLOBAL TOP5（雅典 73 … 布宜诺斯艾利斯 65）；地图上两个 #1 气泡。
- **视觉**：气泡 = 上方 10px mono 标签 + 19px 城市名 + 分值；地图点径 10+分/12。
- **交互**：hover 气泡高亮榜单对应行；点击进城市页。
- **数据**：`rankings.china|global` 前 5；全球 36 城 · 23 城有霞。
- **移动端**：地图 40vh，两栏改为可左右滑的分页。

## 03-04 分布直方图 Distribution

- **目标**：一眼看出「今天大盘好不好」。
- **布局**：6 柱，高 140px；柱宽 1fr，间距 8px；底部标签为等级名 + 城数。
- **内容**：无烧 17 / 微烧 8 / 小烧 1 / 小到中烧 3 / 中到大烧 5 / 大烧 0。
- **视觉**：柱色 = 等级色；柱顶标数值（mono 12px）。
- **交互**：hover 柱 → 高亮地图上该等级的城市。
- **移动端**：柱宽压缩，标签竖排。

## 03-05 城市检视 City Inspector

- **目标**：不离开榜单就能看一个城市的详情。
- **布局**：桌面右侧抽屉 420px；移动底部 sheet 78vh。
- **内容**：城市名 + 分数 + 等级 + 日落时刻（本地）+ 三项门控迷你条 + `查看城市页 →`。

- **交互**：`Esc` 关闭；点击「查看城市页」→ 路由跳转并保留 drawer 关闭动画。
- **移动端**：sheet 顶部 4px 拖拽条。
