## 一句话结论

现状是一个**气质已到位、结构未完成**的单页站（6.6/10）。这次重构把它拆成 3 个可分享、可被搜索的页面，用「一台看天的仪器」作为统一视觉语言，并把首屏从海报改成决策：**今晚 68 分 · 最佳 17:19–17:58 · 方位 257° · 值得跑一趟。**

---

## 三个最重要的改动

1. **首屏决策化**：一屏内给出分数 / 等级 / 窗口 / 方位 / 把握，3 秒完成「去不去」的判断。
2. **六级色阶**：一个 ember 变成六档语义色（无烧→大烧），地图、榜单、柱图、分数共用同一套。
3. **天空即数据**：天幕由真实云量、太阳高度、AOD 驱动；摄影素材只用于观景点，不用于首屏。
