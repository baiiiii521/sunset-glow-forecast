07 — HOW IT WORKS / 算法

这台仪器只有三个旋钮，
其余都在打光。

不展开成一门课。三句话讲完，剩下的交给数字。

幕布权重 0.50

中高云被夕阳从下方点亮，30–70% 最好。

缺口权重 0.30

沿太阳方位往上游 50–400 km，那边要晴。

低云权重 0.20

低云是墙，不挡光的天空才有颜色。

三项几何加权：任何一项接近 0，霞分就接近 0——晴空万里不会被算成中烧。 云量同时取四个数值模式（综合 ×3 / ECMWF / GFS / ICON），再用 51 个集合成员给出概率区间。
