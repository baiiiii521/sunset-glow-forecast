# GLOW · Board（/board 霞榜）+ City（/city 城市七天）页面规范 — 继承 MASTER.md

## BOARD（/board）

1. **HEAD**：mono 标签「BOARD / 霞榜」+ Display 大字标题（「今天，哪里最可能烧。」）+ 日期说明（mono）；全球/中国 pill 切换（role=tablist）；meta 行 = 更新时间 + 池规模
2. **MAP**：左侧 TOP10 名次列表（名次 mono + 城市名 + 分数色点），右侧点阵地图——世界（等距圆柱投影）/中国（含台湾岛、南海诸岛、九段线）切换；点位 = 六级色阶，top3 半径放大；hover tip = 城市+分数；点按城市跳城市页
3. **DUAL 双榜**：两栏编辑表——中国 TOP5 / 全球 TOP5，表头 mono + 统计行（分布计数）；行 = 名次/城市/国家/等级/分数（衬线数字+等级色）
4. **DISTRIBUTION**：六档水平条分布（等级色 + 计数 + mono 标签），标题「今天有多少城市有戏」
5. **INDEX 城市索引**：中国城市搜索（名/省份子串），结果行点击进城市页
6. stale banner：数据超过阈值时顶部黄条提示（仅提示不阻断）
7. 单模式城市标注（mono「单模式」chip）

## CITY（/city?lat=&lon=&name=…）

1. **城市头**：天空照片背景（按当前最高等级联动）+ 回链接「← 回到今晚」+ 城市 Display 大字 + meta（国家 / 坐标 mono / 本地时区）+ 霞榜徽章（今日第 N 名 · 等级）+ 三 tab（七天总览 / 只看晚霞 / 只看朝霞，role=tablist）
2. **TODAY 今天这一场**：当前场次大卡（分数+等级+时间窗+方位+把握），配对场次小卡
3. **WEEK 七天矩阵**：行=日期（今/明/周三…），列=晚霞/朝霞；格子 = 等级色底（20% 透明度）+ 衬线分数；hover 浮起（无位移，边变亮）；点击联动云层剖面切到该场
4. **CLOUD DECK 云层剖面**：SVG 时间轴 × 三层云量带——低云（cream 半透明「墙」）/ 中云（gold「幕布」）/ 高云（rose「幕布」）；时间窗高亮区 + 日落/日出竖线；mono 图例
5. **CONSENSUS 模式分歧**：四模式卡（综合 ×3 权重标注），每家分数色点 + 与综合的偏差箭头；「四家说了算，分歧也是信息」
6. 收藏 / 分享 icon；未在库城市直接按坐标计算

## 通用

- 两页均挂全局 ⌘K 搜索与移动 tabbar
- City 无参数时回到首页并打开搜索面板
- 加载/失败态同 Home 规范（骨架 `--` + 一句话错误 + 重试）
